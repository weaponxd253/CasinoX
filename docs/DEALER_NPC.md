# Blackjack dealer NPC

This slice adds one stationary visual dealer to both `/world/index.html` and
`/floor/index.html`, using their shared `CasinoRoom`. Phaser remains 3.90.0.

## Rendering and assets

The supplied sixteen poses are packed into a 1024 x 1536 RGBA sheet with
256 x 384 frames, foot baseline 368 and no resampling. Direction rows are down
0-3, left 4-7, right 8-11 and up 12-15. Four future walking definitions use
8fps/repeat -1; this phase displays only down idle frame 0. See
`floor/assets/dealer/README.md` and the frame manifest for preparation details.

The foot anchor is world (480, 199), rounded from artwork (768, 340). The
48 x 72 display box matches the owner and receptionist. The existing table
foreground at depth 5/20 covers the dealer's lower body at depth 4; the supplied
background, foreground masks and collision footprints are unchanged. The NPC
has no physics body or interaction zone.

`world/npc-sprite.js` shares loading, validation, nearest-neighbor rendering,
animation registration, fallback and read-only diagnostics. The receptionist
retains its public wrapper, frame mapping, position, depth and dialogue.

## Presentation lifecycle

- IDLE: stationary, downward-facing pose.
- GREETING: entering the existing table approach area displays a greeting in
  the existing status line alongside the E instruction. It opens no dialogue
  and does not consume an interaction. Leaving the area rearms the greeting;
  remaining nearby, including returning from blackjack, does not repeat it.
- PLAYING: the existing overlay's open callback changes presentation state and
  pauses the same lounge scene. Close resets IDLE and uses the existing
  resume/focus path. The iframe remains mounted and the hand is unchanged.

Scene sleep/wake retains the same dealer instance and texture. Hard reload
recreates transient visual state. No NPC state is written to storage, mapped
to actual hotel staffing, or used to calculate cards, bets, payouts or finances.
Missing, invalid or incorrectly sized dealer assets use a small visual fallback
without blocking the room or touching saves.

## Manual interaction check

1. Continue the resort and enter the Blackjack Lounge, or open `/floor/index.html`.
2. Approach the front of the table; the greeting and E prompt appear together.
3. Press E once, play through the existing UI, then use Return to floor or Escape.
4. Verify the owner returns to the same spot and moves normally. In the world
   route, return south to the Central Lobby and reenter; the dealer stays put.

## Limitations

No wandering, staff assignments, dealing animation, new interaction zones or
financial simulation are introduced. Walking animations are registered for
future use only. The existing hard-reload loss of an unfinished blackjack hand
remains: its wager stays deducted, without refunds, restoration or replay.
